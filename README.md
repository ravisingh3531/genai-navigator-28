**H3: Certification vs. Certificate — The Distinction Recruiters Actually Make**

### SECTION 4 — H2: The 2026 GenAI Skill Stack — What a Complete GenAI Certification Must Cover

Seven layers. For each: topics, why it matters, and what most GenAI certifications skip. This doubles as the reader's audit checklist for any syllabus or exam guide.

**Layer 0 — Foundations (the layer GenAI-only courses pretend you don't need).** Python for AI, NumPy, pandas, APIs and JSON, Git/GitHub, core ML concepts (train/test, overfitting, evaluation metrics), neural network intuition, transformers and attention at an intuitive level. Everything above collapses without it; commonly skipped by "no coding required" certifications, which then produce learners who can't debug their own RAG pipeline.

**Layer 1 — LLM Fundamentals.** How LLMs are trained (pre-training, SFT, RLHF/DPO), tokens and tokenisation, context windows, sampling and temperature, model families (proprietary vs. open-weight — Llama, Mistral, Qwen, Gemma, DeepSeek), reasoning models, multi-modal models, cost and latency trade-offs, local inference (Ollama). Commonly reduced to "what is ChatGPT."

**Layer 2 — Prompt Engineering (basic → advanced).** Zero-shot, few-shot, chain-of-thought, role and system prompts, structured outputs and JSON mode, function calling, prompt evaluation and versioning, prompt injection awareness. Now baseline; commonly the entire course.

**Layer 3 — Embeddings, Vector Search & RAG.** Embedding models, vector databases (Chroma, Pinecone, Qdrant, Weaviate, pgvector), chunking strategies, hybrid search, re-ranking, query rewriting, multi-source retrieval, citations, RAG evaluation (faithfulness, relevance, recall), production concerns (freshness, cost, latency). The most-asked GenAI interview topic; commonly one demo notebook.

**Layer 4 — Orchestration: LangChain, LangGraph & LlamaIndex.** Chains, memory, retrievers, tools, LangGraph state machines, LlamaIndex for document pipelines, when to use a framework vs. plain SDK calls. Commonly taught as "import LangChain" without design judgement.

**Layer 5 — Fine-Tuning & Adaptation.** The prompting vs. RAG vs. fine-tuning decision, dataset construction, SFT, PEFT with LoRA/QLoRA, DPO concepts, Hugging Face PEFT/TRL, evaluation against base, compute and cost realities. Commonly labelled "advanced" and dropped.

**Layer 6 — AI Agents & MCP.** Planning, ReAct, tool use, memory, single- and multi-agent patterns, frameworks (LangGraph, CrewAI, AutoGen, OpenAI Agents SDK), MCP for tool and data integration, agent failure modes, cost control, agent evaluation. The fastest-growing hiring requirement; commonly a final-week overview.

**Layer 7 — Evaluation, Guardrails, LLMOps & Deployment.** Evaluation methodology, LLM-as-judge and its pitfalls, hallucination detection, guardrails and PII handling, responsible AI and governance, FastAPI serving, Docker, cloud deployment (Azure OpenAI, Vertex AI, Bedrock), observability (LangSmith and equivalents), prompt versioning, caching and cost optimisation. The layer that separates "built a demo" from "employable"; commonly absent.

> **The Seven-Layer Audit:** Before paying for any certification — including any in this list — take its syllabus or exam guide and mark which layers it covers hands-on, which it covers as theory, and which it skips. If Layer 3 is one notebook, Layer 5 is missing and Layer 7 is a slide, you're looking at a 2023 course wearing a 2026 certificate.

**H3: 6) Honest Limitations — Where LogicMojo Is Not the Right Choice**
